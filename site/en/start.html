Connect any compatible MCP agent

Use direct MCP without Python, or install the thin terminal client. The catalog and recommendation engine stay on the owner's server. A wheel contains readable Python client code.

mumu 0.1.0. The thin client and identified first-party public guides/templates use Apache-2.0. Downloading or building the client grants no hosted-service access. See measured compatibility and limitations.

Recipient prerequisites

  1. Obtain an existing authorized API key and service URL through your administrator's private channel. Continue only when you have both values privately. If you lack access, stop and contact that administrator; a download does not grant access.
  2. Choose direct MCP if your agent meets the connection requirements. Follow its discovery and authenticated-call checks before using recommendations. Otherwise use the CLI if the agent can run shell commands.

These guides serve existing approved key holders. They do not open registration or extend access. Windows is outside the initial matrix. See compatibility and release history.
