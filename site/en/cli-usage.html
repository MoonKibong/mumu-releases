CLI usage

You or an agent with shell access can run these commands. The CLI is a remote client, not a stdio MCP server. Follow Connect first. The examples use English; add --lang ko to recommend, show and intake-form for Korean results.

  1. Run the first recommendation below for your own problem. A successful JSON result supplies identifiers for use within your private session. Set PATTERN_ID and OTHER_PATTERN_ID only from that private session; do not invent example identifiers.
  2. If intake is useful, run intake-form without redirecting it into a repository. Read the returned form and its version before preparing answers. Prepare intake.json privately using that version and evidence from the exact problem; leave unstated answers unknown. If the version is stale, fetch a new form and rebuild answers.
  3. If you supply declared context, create context.json in a private temporary workspace from facts and paths accepted by the advertised schema. Use it with the recommendation command below; the service must accept the input. Do not invent registered facts. The context and intake are separate inputs; intake does not overwrite context.
  4. Run show and related using returned identifiers. Each command must return successful JSON. Before a combination, create couplings.json as a list of two-identifier arrays naming actual edges, then run check. Use the result to review only checked couplings and preserve unregistered ones as unverified.
mumu --server "$MUMU_BASE_URL" recommend 'Our shared calendar loses an unsaved edit when a colleague updates the same event.' --lang en --format json
mumu --server "$MUMU_BASE_URL" intake-form software --lang en --format json
mumu --server "$MUMU_BASE_URL" recommend 'Our shared calendar loses an unsaved edit when a colleague updates the same event.' --context context.json --intake intake.json --format json
mumu --server "$MUMU_BASE_URL" show "$PATTERN_ID" --lang en --format json
mumu --server "$MUMU_BASE_URL" related "$PATTERN_ID" --context context.json --format json
mumu --server "$MUMU_BASE_URL" check "$PATTERN_ID" "$OTHER_PATTERN_ID" --couplings couplings.json --context context.json --format json

JSON is the default; --format text is available. Keep input files and output private and outside tracked repositories. Delete temporary forms/answers/context/couplings after the task. If a call fails, follow Troubleshoot; do not treat an error as a recommendation.
