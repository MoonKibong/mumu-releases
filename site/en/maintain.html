Maintain the client

mumu 0.1.0 uses Apache-2.0 for the identified first-party materials. Installation lifecycle was measured on macOS arm64 Python 3.11.14/3.15.0 and Linux aarch64 Python 3.11.18/3.15.2, each with Bash and Zsh. It covered fresh public dependency resolution, hidden session input, child-process inheritance, activated PATH, Apache metadata/notices, help, same-version reinstall and uninstall. Each runtime resolved 29 distributions: mumu and 28 third parties, with notice-file and download hashes recorded. This inventory is not legal signoff. Exported-source build/install was measured on macOS arm64 Python 3.11.14 only.

Historical five-tool discovery, protocol negotiation (2025-11-25), installed CLI/intake and explicit Codex CLI 0.167.1/Claude Code 2.1.322 tool calls cover unchanged runtime and template inputs. They do not establish authentication of every rebuilt wheel, current deployment/agent versions or model-driven behavior; both agent checks used zero model invocations. Other protocol versions remain unverified.

Chrome 157.0.8103.51 checks covered EN/KO start/install/maintain at 390×728, EN maintain at 1280×800, and EN/KO install keyboard navigation plus the EN start LICENSE link. These are named guide surfaces and responsive emulation, not physical-device or authenticated browser-MCP certification. Other operating systems, architectures, runtime versions and browser surfaces are unverified. This initial release has no previous release for cross-version upgrade or rollback.

  1. For an approved upgrade, follow that version's pinned download and hash instructions in a new environment. Require the expected metadata version and a successful private authenticated call before switching environments. Keep the previous approved environment until then. Do not overwrite assets under an existing version.
  2. For a same-version reinstall after hash verification, run python -m pip install --force-reinstall ./mumu-0.1.0-py3-none-any.whl inside the selected isolated environment. Repeat the help and metadata commands from Install; both must still report the expected client. If resolution fails, retain the working environment and contact private support.
  3. To uninstall, run python -m pip uninstall mumu inside the selected environment. Run python -m pip show mumu; it must report that the package is absent. Exit any running agent and unset MUMU_API_KEY.
  4. If a release is withdrawn, stop using its download recommendation. For an initial release with no previous artifact, uninstall it. For later releases, use only an approved previous version with its original checksum and isolated environment, then repeat authentication. Cross-version rollback is unverified until such an artifact exists.

Private support: contact the administrator who supplied your key through that same private channel. Do not open a public issue containing service URLs, problems, retrieved content or secrets. A suspected disclosure goes to that administrator immediately; public deletion cannot retract copies. This client release performs no server migration.
