Connect privately

The CLI requires the service base URL; it appends /mcp. Direct MCP requires the full HTTPS URL ending in /mcp. The placeholder https://mumu.example.invalid is deliberately unreachable.

  1. Set the base URL in the current shell: MUMU_BASE_URL='https://mumu.example.invalid', replacing the placeholder with the privately supplied base URL. Use a base URL without the /mcp suffix. Do not include a key, userinfo or query string in a URL.
  2. Source the matching session snippet below in your interactive shell and type the key at its hidden prompt. Run test -n "$MUMU_API_KEY"; it must exit zero. If input fails, stop and retry privately. Do not print the variable.
  3. Start or fully restart your agent from that same shell. Confirm that direct MCP discovers all five tools and makes one authenticated call by following Agent setup. A running agent cannot inherit a later environment change. If the CLI path is selected, run the first recommendation in CLI usage and require a successful JSON response.

Bash session

# Recipient: source this file in an interactive bash session with tracing disabled.
# Do not execute it as a child process: the agent must inherit this shell's environment.
set +x
IFS= read -r -s -p "Mumu API key: " MUMU_API_KEY || return 1
printf '\n'
[ -n "$MUMU_API_KEY" ] || return 1
export MUMU_API_KEY
# Success: test -n "$MUMU_API_KEY". Do not print its value.

Zsh session

# Recipient: source this file in an interactive zsh session with tracing disabled.
# Do not execute it as a child process: the agent must inherit this shell's environment.
set +x
IFS= read -r -s "MUMU_API_KEY?Mumu API key: " || return 1
printf '\n'
[ -n "$MUMU_API_KEY" ] || return 1
export MUMU_API_KEY
# Success: test -n "$MUMU_API_KEY". Do not print its value.

Keep keys out of arguments, URLs, chat, tracked files, browser forms/storage and diagnostics. Do not use a persistent installer export. If persistent environment setup is separately requested on the operator's machine, the operator puts exports only in ~/.config/shell/env.sh; do not edit startup profiles. At session end run unset MUMU_API_KEY and exit the agent.
