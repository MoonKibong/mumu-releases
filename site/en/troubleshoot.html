Troubleshoot

Stop the affected step on failure. Use the corresponding recovery below; retry the original command and require success. Contact your issuing administrator privately if it still fails. Send only the client/agent version and sanitized error category, never keys or authenticated responses.

ObservationRecovery and check
Python missing or incompatibleInstall the selected 3.11 or 3.15 runtime through your approved method; its --version must report that version.
Dependency unavailableCheck public index/network policy privately. Retry isolated installation without private indexes. Do not replace mcp==2.3.0 or httpx2==2.16.0. If unresolved, installation remains blocked.
mumu not found / wrong PATHActivate the selected environment or use its bin/mumu absolute path. command -v mumu must point inside it.
Missing key / 401Repeat hidden session input and restart the agent. If rejected again, ask the administrator to inspect existing authorization privately. Do not request or issue keys through this guide.
Host rejectedCompare the privately supplied HTTPS base URL with your setting. Do not bypass host checks or change the server. Ask the administrator if it still fails.
Network timeout / protocol mismatchCheck approved network access and the agent's Streamable HTTP capability. Retry once. If it fails, report the category privately; do not change transports.
Quota errorWait until the returned reset time. Retry once after reset. Do not repeatedly probe or exhaust the allowance.
Stale form versionFetch get_intake_form again. Rebuild answers from your problem with the returned version. Do not edit a cached version string or invent answers.
Invalid JSON or unreadable fileCorrect the private JSON input and permissions. Re-run the same command; require successful JSON output.
