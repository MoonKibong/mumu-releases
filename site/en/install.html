Install the client

Installation lifecycle was measured on macOS arm64 with Python 3.11.14/3.15.0 and Linux aarch64 with Python 3.11.18/3.15.2, each with Bash and Zsh. See coverage and limitations. Direct MCP needs neither Python nor this installation.

  1. Run python3.11 --version (or python3.15 --version). The output must report the selected version. If it is missing, install that supported Python through your organization's approved method before continuing.
  2. Download each file with the six curl commands below. Continue only when each command exits zero. If any URL is unavailable, stop; do not substitute a floating latest URL.
  3. Run the SHA-256 command. It must print SHA-256 OK. Compare the wheel hash with the approved hash supplied privately by your administrator. If either comparison fails, delete the downloads and stop. A checksum from the same download origin alone does not prove authenticity.
  4. Read LICENSE, NOTICE and DISTRIBUTION-NOTICE.txt. The identified first-party client is Apache-2.0; no personal owner permission is required to exercise its license rights. Service access still requires existing authorization.
  5. Create the isolated environment and run its pip install command below. Continue only when both commands exit zero. Public dependencies must resolve without private indexes or caches. If resolution fails, follow Troubleshoot; do not replace the pinned dependencies.
  6. Activate that environment and run the final three checks below. The executable must be inside that environment, help must exit zero, and metadata must print 0.1.0. If another executable appears, use the environment's absolute executable path.

The block uses Python 3.11. For the required Python 3.15 cell, replace both python3.11 occurrences and the checksum command's interpreter with python3.15. Run each command separately.

# Recipient: run each step separately. Stop if a command fails.
curl --fail --location --remote-name 'https://github.com/MoonKibong/mumu-releases/releases/download/v0.1.0/mumu-0.1.0-py3-none-any.whl'
curl --fail --location --remote-name 'https://github.com/MoonKibong/mumu-releases/releases/download/v0.1.0/SHA256SUMS'
curl --fail --location --remote-name 'https://github.com/MoonKibong/mumu-releases/releases/download/v0.1.0/LICENSE'
curl --fail --location --remote-name 'https://github.com/MoonKibong/mumu-releases/releases/download/v0.1.0/NOTICE'
curl --fail --location --remote-name 'https://github.com/MoonKibong/mumu-releases/releases/download/v0.1.0/DISTRIBUTION-NOTICE.txt'
curl --fail --location --remote-name 'https://github.com/MoonKibong/mumu-releases/releases/download/v0.1.0/RELEASE-NOTES.txt'
python3.11 -c 'import hashlib,pathlib; rows=[line.split("  ") for line in pathlib.Path("SHA256SUMS").read_text().splitlines()]; expected={"mumu-0.1.0-py3-none-any.whl","DISTRIBUTION-NOTICE.txt","RELEASE-NOTES.txt","LICENSE","NOTICE","mumu-0.1.0-client-source.zip"}; assert len(rows)==len(expected) and {n for h,n in rows}==expected; assert all(hashlib.sha256(pathlib.Path(n).read_bytes()).hexdigest()==h for h,n in rows if n!="mumu-0.1.0-client-source.zip"); print("SHA-256 OK")'
python3.11 -m venv "$HOME/.local/share/mumu/0.1.0"
"$HOME/.local/share/mumu/0.1.0/bin/python" -m pip install './mumu-0.1.0-py3-none-any.whl'
. "$HOME/.local/share/mumu/0.1.0/bin/activate"
command -v mumu
mumu --help
python -c 'import importlib.metadata; assert importlib.metadata.version("mumu")=="0.1.0"; print("0.1.0")'

Activation changes PATH only in the current session. This procedure does not edit shell startup files. See Connect for session credentials.

The client-only source ZIP contains build instructions in README.txt. Before building, compare its SHA-256 with SHA256SUMS and the exact approved hash supplied privately by your administrator. If either differs, stop. This archive is generated from the allowlisted client export.
