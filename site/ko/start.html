호환되는 모든 MCP 에이전트 연결

Python 없이 MCP로 직접 연결하거나 터미널용 경량 클라이언트를 설치한다. 카탈로그와 추천 엔진은 소유자의 서버에만 둔다. wheel에는 읽을 수 있는 Python 클라이언트 코드가 포함된다.

mumu 0.1.0. 경량 클라이언트와 명시된 자사 공개 가이드·템플릿은 Apache-2.0을 사용한다. 클라이언트를 다운로드하거나 빌드해도 호스팅 서비스 접근 권한은 생기지 않는다. 측정된 호환성과 제한을 참고한다.

수신자 사전 조건

  1. 수신자는 관리자에게 비공개 채널로 기존에 승인된 API 키와 서비스 URL을 받는다. 두 값을 비공개로 확보한 뒤 진행한다. 접근 권한이 없으면 중단하고 해당 관리자에게 문의한다. 다운로드는 접근 권한을 부여하지 않는다.
  2. 수신자는 연결 요건을 충족하는 에이전트라면 직접 MCP 연결을 선택한다. 연결 페이지의 다섯 도구 검색과 인증 호출이 성공한 뒤 추천을 사용한다. 요건을 충족하지 못하면 셸 실행이 가능한 경우 CLI를 사용한다.

대상은 기존 승인된 키 보유자다. 가입을 받거나 접근 범위를 넓히지 않는다. Windows는 최초 행렬에 포함되지 않는다. 호환성 및 릴리스 기록을 참고한다.
