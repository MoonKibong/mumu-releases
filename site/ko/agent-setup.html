호환되는 모든 MCP 에이전트 연결

수신자는 에이전트의 MCP 설정에 다음 기능을 설정한다. 아래 항목은 연결 요건이며 공통 JSON 설정 스키마가 아니다. 직접 MCP 연결에는 Python이 필요 없다.

기능요건
전송HTTPS 원격 Streamable HTTP
엔드포인트비공개 서비스 기본 URL 뒤에 /mcp 추가
인증에이전트 비밀 관리 기능으로 MUMU_API_KEY를 Authorization bearer 헤더에 전달
프로토콜배포 서버가 지원하는 버전 협상
호출도구 검색 후 각 도구가 알리는 JSON 인자 스키마 준수
  1. 제품 설정과 연결의 세션 키로 위 요건을 적용한다. 설정에는 키 참조와 비공개 엔드포인트가 있어야 한다. 설정 텍스트에 키를 붙여 넣지 않는다.
  2. 키를 입력한 셸에서 에이전트를 재시작한다. 인증된 MCP 연결이 표시되어야 한다. OAuth 전용 또는 stdio 전용이면 이 직접 경로는 지원되지 않는다. 셸 도구가 있으면 CLI를 사용한다. 두 경로 모두 사용할 수 없으면 관리자에게 비공개로 문의한다.
  3. 에이전트에서 도구를 검색한다. 검색 결과에 recommend_patterns, get_pattern, get_related_patterns, check_composition, get_intake_form과 각 인자 스키마가 있어야 한다. 하나라도 없으면 중단하고 관리자에게 비공개로 문의한다.
  4. 검색된 스키마에 따라 본인이 작성한 일반 문제로 recommend_patterns를 호출하게 한다. 인증된 성공 결과를 받은 뒤에만 추천을 사용한다. 응답을 공개 로그에 저장하지 않는다. 협상이 실패하면 비공개로 보고한다. 최신 MCP 명세로 호환성을 추정하지 않는다.

과거의 독립 도구 검색과 인증 호출에서 프로토콜 2025-11-25를 협상했다. 현재 배포나 지원 버전 전체를 입증하지 않으며 다른 버전은 미검증이다. 제품의 MCP 표기만으로 요건이 증명되지 않는다. 브라우저는 서버 origin/CORS 정책도 맞아야 하며 브라우저 지원은 미검증이다.

제품 예시와 측정된 상호운용성

Codex CLI: ~/.codex/config.toml에 아래 템플릿을 넣고 URL만 비공개 전체 엔드포인트로 바꾼 뒤 같은 셸에서 재시작한다. bearer 환경 설정의 근거는 공식 Codex MCP 문서다.

[mcp_servers.mumu]
url = "https://mumu.example.invalid/mcp"
bearer_token_env_var = "MUMU_API_KEY"

Claude Code: 비공개이며 추적하지 않는 수신자 작업 공간의 .mcp.json에 아래 JSON을 적용하고 URL만 바꾼 뒤 재시작한다. type: http와 환경 참조를 유지한다. 공식 Claude Code MCP 문서를 참고한다. 키를 포함하는 헤더 추가 명령을 실행하지 않는다.

{
  "mcpServers": {
    "mumu": {
      "type": "http",
      "url": "https://mumu.example.invalid/mcp",
      "headers": {
        "Authorization": "Bearer ${MUMU_API_KEY}"
      }
    }
  }
}

과거 macOS 검사에서 Codex CLI 0.167.1과 Claude Code 2.1.322의 실제 MCP 호스트로 도구 5개 검색과 명시적 인증 도구 호출을 수행했고 모델 호출은 0회였다. 이 증거는 변경되지 않은 표준 설정 입력에 적용되며 현재 설치된 에이전트 버전, 모델 주도 동작이나 모든 대화형 모드를 입증하지 않는다. 검증 범위와 제한을 참고한다.
