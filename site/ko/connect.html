비공개 연결

수신자가 수행한다. CLI에는 서비스 기본 URL을 전달한다. CLI가 /mcp를 붙인다. 직접 MCP 설정에는 /mcp로 끝나는 전체 HTTPS URL을 쓴다. https://mumu.example.invalid는 의도적으로 연결할 수 없는 자리표시자다.

  1. 현재 셸에서 MUMU_BASE_URL='https://mumu.example.invalid'의 자리표시자를 비공개로 받은 기본 URL로 바꿔 설정한다. /mcp 접미사가 없는 기본 URL을 쓴다. URL에 키, 사용자 정보, 쿼리 문자열을 넣지 않는다.
  2. 현재 대화형 셸에서 아래 해당 스니펫을 source하고 숨김 프롬프트에 키를 입력한다. test -n "$MUMU_API_KEY"를 실행한다. 0으로 종료되어야 한다. 실패하면 중단하고 비공개로 다시 입력한다. 변수 값을 출력하지 않는다.
  3. 같은 셸에서 에이전트를 시작하거나 완전히 재시작한다. 에이전트 설정에 따라 다섯 도구 검색과 인증 호출이 성공한 뒤 사용한다. 실행 중인 에이전트는 이후 변경된 환경을 상속하지 못한다. CLI를 선택했으면 CLI 사용의 첫 추천 명령을 실행하고 성공한 JSON 응답을 요구한다.

Bash 세션

# Recipient: source this file in an interactive bash session with tracing disabled.
# Do not execute it as a child process: the agent must inherit this shell's environment.
set +x
IFS= read -r -s -p "Mumu API key: " MUMU_API_KEY || return 1
printf '\n'
[ -n "$MUMU_API_KEY" ] || return 1
export MUMU_API_KEY
# Success: test -n "$MUMU_API_KEY". Do not print its value.

Zsh 세션

# Recipient: source this file in an interactive zsh session with tracing disabled.
# Do not execute it as a child process: the agent must inherit this shell's environment.
set +x
IFS= read -r -s "MUMU_API_KEY?Mumu API key: " || return 1
printf '\n'
[ -n "$MUMU_API_KEY" ] || return 1
export MUMU_API_KEY
# Success: test -n "$MUMU_API_KEY". Do not print its value.

키를 인자, URL, 채팅, 추적 파일, 브라우저 폼·저장소, 진단 로그에 넣지 않는다. 설치 도구가 영구 export를 만들지 않는다. 운영자 기기에서 영구 환경 설정을 별도로 요청한 경우 운영자는 export를 ~/.config/shell/env.sh에만 둔다. 시작 프로필을 수정하지 않는다. 세션 종료 시 unset MUMU_API_KEY를 실행하고 에이전트를 종료한다.
