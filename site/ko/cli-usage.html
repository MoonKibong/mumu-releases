CLI 사용

수신자 또는 셸 실행 가능한 에이전트가 수행한다. CLI는 원격 클라이언트이며 stdio MCP 서버가 아니다. 먼저 연결을 따른다. 아래는 영어 예시다. 한국어 결과는 recommend, show, intake-form에 --lang ko를 준다.

  1. 본인 문제로 아래 첫 추천을 실행한다. 성공한 JSON 결과에서 현재 비공개 세션에 사용할 식별자를 얻는다. PATTERN_ID와 OTHER_PATTERN_ID에는 해당 세션에서 받은 값만 설정한다. 예시 식별자를 만들지 않는다.
  2. 인테이크가 유용하면 intake-form을 실행한다. 저장소 파일로 리다이렉트하지 않는다. 답을 작성하기 전에 반환된 폼과 버전을 읽는다. 그 버전과 정확히 같은 문제의 근거로 intake.json을 비공개로 작성한다. 언급되지 않은 답은 unknown으로 둔다. 버전이 오래됐으면 새 폼을 받고 답을 다시 작성한다.
  3. 선언 문맥을 보낼 경우 공개된 인자 스키마가 허용하는 사실·경로로 비공개 임시 작업 공간에 context.json을 만든다. 아래 추천 명령에 사용했을 때 서비스가 입력을 수락해야 한다. 등록된 사실을 임의로 만들지 않는다. 문맥과 인테이크는 별개 입력이며 인테이크가 문맥을 덮어쓰지 않는다.
  4. 반환된 식별자로 show와 related를 실행한다. 각 명령이 성공한 JSON을 반환해야 한다. 조합 전에는 실제 연결을 식별자 두 개의 배열 목록인 couplings.json으로 작성하고 check를 실행한다. 반환된 결과에서 검사된 결합만 판단하고 미등록 결합을 미검증으로 남긴다.
mumu --server "$MUMU_BASE_URL" recommend 'Our shared calendar loses an unsaved edit when a colleague updates the same event.' --lang en --format json
mumu --server "$MUMU_BASE_URL" intake-form software --lang en --format json
mumu --server "$MUMU_BASE_URL" recommend 'Our shared calendar loses an unsaved edit when a colleague updates the same event.' --context context.json --intake intake.json --format json
mumu --server "$MUMU_BASE_URL" show "$PATTERN_ID" --lang en --format json
mumu --server "$MUMU_BASE_URL" related "$PATTERN_ID" --context context.json --format json
mumu --server "$MUMU_BASE_URL" check "$PATTERN_ID" "$OTHER_PATTERN_ID" --couplings couplings.json --context context.json --format json

기본 출력은 JSON이며 --format text도 지원한다. 입력과 출력은 추적 저장소 밖에서 비공개로 다룬다. 작업 후 임시 폼·답·문맥·결합 파일을 삭제한다. 실패하면 문제 해결을 따른다. 오류를 추천 결과로 취급하지 않는다.
